# cubrid-importdb -- the upstream surface this repo depends on.
#
# One line per requirement. `check_surface.sh` reads this file and verifies it
# either against a CUBRID *install* (--install <dir>) or against a CUBRID
# *source tree* (--source <dir>). The source mode is what the engine repo runs
# on every PR: it costs seconds and catches the declaration-level breakage that
# is most of what actually breaks.
#
# Format:  <kind> <arg> [arg...]
#   header      <name>                     must be installed
#   install     <name>                      the engine CMake must install it
#   decl        <header> <symbol>           the header must declare the symbol
#   export      <symbol>                    libcubridcs must export it unmangled
#   const       <file> <name> <value>       a value replicated in this repo
#   grep        <file> <regex> <why>        a contract expressed as source shape

# ---- source-shape contracts
grep src/executables/util_admin.c util_get_utility_index.*argv cub_admin resolves the utility name from its own argv -- this is what lets the data phase exec `cub_admin loaddb ...` directly and keep the loader a DIRECT child, which is what PR_SET_PDEATHSIG needs
grep src/executables/util_admin.c UTIL_OPTION_IMPORTDB the importdb utility is still registered in the admin utility map
grep src/loaddb/load_server_loader.cpp HA_DISABLED the HA per-record fallback gate is still where the loaddb umbrella measured it (plan/loaddb I63) -- if this moves, the ha_mode guidance the utility prints is stale
